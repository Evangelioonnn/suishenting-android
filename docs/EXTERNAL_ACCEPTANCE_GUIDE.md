# 随身听外部条件验收操作表

本表承接[主计划](RELEASE_STATUS.md)的原验收条件。当前用户已说明手机、耳机和云配置稍后准备，本表只准备步骤，不表示已经执行。实际安装包、源码与哈希以[v0.9.4修复验收报告](RELEASE_STATUS.md)的固定候选为准；全部验收通过前不正式交付。

用户主要提供实际使用的手机、有线及蓝牙耳机、可用的讯飞和百度配置，以及声音与录音的体验反馈。样本准备、自动采集、数据核对、失败分析和报告更新仍由开发者负责，不能把本机开发和回归工作转交给用户。

## 准备

1. 在现有版本导出完整备份，确认原录音和文稿可保留；有待确认录音时先处理。沿用原证书覆盖安装候选，不卸载或清除应用数据。
2. 登记手机型号、Android版本、内存、空闲空间、系统字号、中文离线声音和候选哈希。使用单独的合成验收文稿和新录音，不在唯一原资料上制造故障。
3. 云密钥只通过本机应用填写，不发送到聊天，不截图、不写入报告。确认两个账户各有相应音色授权和少量测试额度。
4. 按下表分别登记“通过／失败／未执行”，保留起止时间、实际结果、脱敏日志和必要画面。失败时保留原内容与现场，开发者定位后重做受影响项目。

## 结果回填与正式交付

开发者将每项实际结果写回主计划和验收报告，并核对候选源码、签名与哈希。任何影响安装包的修正都须重建和重做受影响检查及全局冒烟。

A17-04仍保留“证书确需变更时”的原条件；本轮沿用原证书，不为了减少待验项更换证书。A18的全组回归、完整证据与最终交付条件在外部项目通过后由开发者继续收口。这些交付依赖不等于另外要求用户执行开发工作。
