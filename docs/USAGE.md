# 随身听使用说明

本文对应 v0.9.3 验收候选。正式交付状态以 [验收摘要](RELEASE_STATUS.md) 和[验收摘要](RELEASE_STATUS.md)为准；全局复查尚有[四项边界问题](KNOWN_ISSUES.md)留待下一轮。

## 创建、查看与播放

首页可以从剪贴板新建，或导入 TXT、DOCX。TXT 支持 UTF-8、UTF-16 和 GB18030/GBK。旧 DOC 请先在 Word 中另存为 DOCX。正文上限为 100 万个 UTF-16 字符；文件上限 20 MB，超限时原有文稿保持不变。损坏编码会提示重新另存，DOCX 正文解压上限 8 MB、包内总展开上限 64 MB；拒绝不安全文档声明。

文稿、草稿和路线等名称最长1000个UTF-16字符（少数补充字符占两个单位），超过时缩短名称后再保存。既有异常超长路线会提示当前为略缩显示；只调整路线内容或顺序时保留数据库原名称，重新输入合规名称可修正。旧异常超长文稿名的读取问题仍在待修清单中。

查看另一篇文稿不会切换正在播放的文稿。首页迷你播放器始终控制真实播放会话；阅读页的“播放本文”才会切换声音。暂停时点击句子只定位，播放时点击句子会从该句句首继续。暂停后继续也从当前句句首开始。自然读完后再播放会从第一句开始；主动停止保留原位置。

范围循环先暂停，依次选择起点和终点，确认范围后再播放。取消选择恢复原模式和范围，保持暂停。主动点击范围外的句子会退出范围循环。

手动浏览后暂停自动跟随，点“回到当前句”恢复跟随。搜索、重点句定位只移动浏览位置；明确点击搜索结果的“朗读”或重点句的“从该句朗读”才改变播放位置。搜索忽略英文大小写，标点和换行按实际文字匹配。

## 声音、倍率与定时

默认优先使用有效本人录音，然后首选云缓存、其他云缓存，最后使用系统中文声音。关闭云声音会跳过云缓存并保留文件。本人录音和缓存不要求系统安装中文 TTS。

播放器显示实际音源及本句生效倍率。本文可以指定倍率，或恢复跟随全局默认。三类音源使用同一倍率；音调只对系统声音有效。播放中的设置变化从下一句起生效。

定时停止位于播放器附近，支持 15、30、60 分钟。计时由播放服务管理，页面切换和系统时间调整不改变剩余时长。重启仅恢复暂停的位置和模式，由用户主动播放。音频被抢占或耳机断开后暂停，由用户主动继续。

TalkBack等短提示仅请求临时降音时，本人录音和云缓存降低音量，系统声音等待提示结束后从当前片段继续。来电、必须停止的焦点抢占和耳机断开仍会暂停，不自动续播。

## 编辑与草稿

草稿与正式文稿分开。持续输入时定期保存可恢复草稿，只有写入成功才显示“草稿已保存”。发现未提交草稿时，可以继续草稿，或使用正式版本。

“保存”提交当时的内容，保持编辑位置；保存期间的新输入继续保留为草稿。退出有修改的编辑可选择保存并退出、继续编辑、放弃修改。横屏或正文键盘显示时，编辑区优先显示正文；文稿名称与统计可以从“更多”打开。正文查找使用独立输入框，结果的上下处导航保持可见。只有正文变化才保留旧版本，最多 5 版。恢复旧版本前先保存当前修改，当前正式内容也会进入历史。

名称、查找、导入预览和路线输入框可以整体上下滚动；键盘打开或字号较大时，向上滚动即可到达底部操作。查找还可以直接使用键盘搜索键。确认查找后键盘收起，上一处/下一处用于浏览命中；需要继续输入时，点击正文即可重新打开键盘。编辑文稿名称后点“完成”只是关闭输入框，仍需在编辑页点“保存”才提交正式内容。

保存失败时，当前输入仍在编辑页，请检查手机存储空间后再点“保存”。只有出现已保存提示才代表相应内容保存成功；请勿通过清除应用数据处理保存或恢复失败。

发现草稿后选择“使用正式版本”，会在成功放弃草稿后继续；操作失败时保留草稿和选择入口，可以检查空间后重试。若提示正式文稿已保存但后续整理未完成，表示正文已经提交，可以稍后重试保存以完成整理。

较长的编辑错误可在“查看原因”中重新打开。备份、导入和云任务等错误会持续显示；可按提示重新选择文件或保存位置、检查云设置，或返回原页面重试。

## 路线与录音

路线只是现有文稿的组织关系，可以调整顺序、继续上次位置、进入上一站或下一站。到篇末由用户决定是否进入下一篇。删除路线不会删除文稿。

录音开始前暂停朗读和试听。停止采集后先保留完整原文件，试听确认后才替换有效录音；不会固定截去首尾。取消或无效重录不替换原录音。离开录音时选择保存或放弃；切后台或中断后尽量保留为待确认录音，可在录音页或存储维护继续处理。

## 删除、存储与恢复

删除文稿后可以立即撤销，也可以在设置的“存储维护、最近删除与恢复点”中恢复。最近删除至少保留 7 天，到期后仍由用户明确确认永久清理。本人录音不会自动永久清除。

移除当前句录音会先保留为旧音频；旧音频可以试听，并在所属句子仍匹配时恢复。用于历史、恢复区、待确认录音或正在播放的文件不会被当作普通旧文件清理。清理云缓存不会删除本人录音。

无法确认所属句子的文件会保留并显示在维护页。不要把这些文件误认为已经进入完整文稿备份。

## 备份与恢复

备份入口在设置中。新 ZIP 包包含正式与最近删除文稿、稳定句子、重点句、路线、历史、草稿、已关联的新旧音频及非密钥设置。云密钥、实际计费信息、恢复点 ZIP 本身和未关联文件不嵌套进入备份。待确认录音须先处理后再导出，避免遗漏本次录音。

单音频不超过 100 MB，清单不超过 30 MB，总展开大小不超过 2 GB。超限或缺失音频会明确报告，本次不会伪报完整备份成功。历史 APK 和本机原资料不会因此删除。

恢复顺序为读取校验、预览、选择策略、执行、核对结果。同ID的正文相同但录音或云缓存不同，也会提示冲突；默认保留本机内容及音频。需要旧资料时可以另存副本，或明确选择覆盖。覆盖前自动保留完整恢复点，可在存储维护中重新校验并恢复。缺失或损坏音频需要明确确认部分恢复，并逐项查看结果。

完全相同的备份副本会复用；已经编辑过、保存新草稿或补录音的副本会保留，再另存独立副本。恢复成功后回到文稿列表，从列表重新打开需要的文稿。预览后相关资料变化时，需要重新选择和校验备份。

备份中的历史快照缺必要字段或引用不完整时会在提交前拒绝。若本机原历史已异常，维护页会告警并保护该文稿相关旧音频；保留原备份后再处理，不通过永久清理绕过。导出也会预检格式和名称上限，不能导出自身无法恢复却提示完整成功的包。

新版本仍读取旧 JSON 和 ZIP。重复导入同一备份不会无故复制资料。恢复失败或中断后重新打开应用，由恢复日志整理已提交或尚未提交的操作；不要手动删除应用数据来处理失败。

## 联网与隐私

文稿默认保存在本机。主动生成或试听云声音，会把相应文字发送给选定的讯飞或百度服务。密钥由 Android Keystore 加密后保存在本机，不进入应用备份。

本机字数统计与提供商实际账单不同。取消会停止本机后续请求，但已提交的请求可能仍被提供商处理或计费，以服务商控制台为准。密钥读取失败时原加密资料保留，本地文稿和本地音频仍可使用。
