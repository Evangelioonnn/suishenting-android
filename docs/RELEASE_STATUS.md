# v0.9.13-rc.1 验收摘要

应用包名 `com.museum.reader`，版本 0.9.13（22），Room 数据库版本 2。下载包沿用原签名，大小 16,682,700 字节，SHA-256 为 `4072C5546FDCFC83DCA1524F6806AD3F37411B3FF4523D241D729BE197FCC12D`。[下载与来源清单](https://github.com/Evangelioonnn/suishenting-android/releases/tag/v0.9.13-rc.1)

| 本机项目 | 已取得的结果 |
|---|---|
| 构建与静态检查 | 禁用构建缓存，126 个任务实际执行。45 项 JVM 单元通过，零失败、错误及跳过。Debug 和 Release lint 各 0 错误、10 条既有警告。 |
| Android 模拟器 | Android 8.0、9、13、16 各通过同一套 145 项主回归，共 580 次，零跳过。Android 13 首批一次界面测试异常，定点两次及整批重跑通过。 |
| 覆盖升级 | 从原签名 v0.9.12 直接升级，两句相同文字各自的录音 ID、句子 ID、路径及音频 SHA-256 均保持，两个文件均能解码。正文、草稿、历史、书签、路线、朗读位置与设置通过核对。 |
| 中断与重试 | 录音同时保存和放弃、提交中断后重试、损坏录音隔离及带遗漏说明的备份恢复通过。草稿实际结束进程再读回，名称和正文哈希一致。云服务替身已返回音频后，实际本地文件及数据库故障均未触发第二次请求。 |
| 长文和输入 | 百万字从应用入口导入、旋转和取消通过。跨页修改与最终入库全文逐字一致。200% 字号、横屏、弹出真实软键盘后保有焦点，收起键盘并确认后读回修订。 |

Android 13 模拟器热进程测量，每项 20 次。打开十万字和百万字的 P95 分别为 265 ms 和 551 ms，百万字输入到首次绘制 P95 为 71 ms。百篇文稿连续操作 40 轮，在测量期间未观察到无响应或内存溢出。真实手机的 100 ms 输入条件仍待测。[已知观察](KNOWN_ISSUES.md)
